# Hospital & Clinic Management System - Multi-Tenant SaaS ERP Project

A fully functional web-based Hospital & Clinic Management System - Multi-Tenant SaaS ERP Project built using PHP, MySQL, Bootstrap, designed for managing hospital operations like patients, doctors, pharmacy, lab reports, and more.

## Features
### Admin Panel
1. Manage patients & staff
2. Assign departments & roles
3. Transfer employees
4. Manage inventory & assets
5. Pharmacy & prescription control
6. Accounting (payables & receivables)
7. Vendor management
8. Payroll generation & printing
## Doctor / Employee Panel
1. Manage patients assigned
2. Add prescriptions
3. View lab reports & vitals
4. Access payroll details
5. Update profile
## Patient Management
1. Add / update / discharge patients
2. Inpatient & outpatient tracking
3. Medical history records
## Pharmacy System
1. Medicine categories & inventory
2. Barcode-based medicine tracking
3. Prescription management
## Laboratory System
	1. Lab test records
	2. Patient vitals tracking
	3. Lab reports generation
## Accounting & Payroll
1. Salary management
2. Payroll generation & receipt printing
3. Expense tracking (payables/receivables)
## Advanced SaaS ERP Version (In Progress)
## Hospital & Clinic Management System – Multi-Tenant SaaS ERP Project
Designing a multi-tenant SaaS-based healthcare platform using Laravel, Redis, Docker, and REST APIs
Implementing patient management, appointment scheduling, billing, and role-based access modules
Exploring scalable backend architecture concepts including caching, queue systems, and tenant isolation
Building secure APIs and notification workflows for healthcare operations management
## Tech Stack
	Frontend: HTML, CSS, Bootstrap
	Backend: PHP (Core PHP)
	Database: MySQL
	Server: XAMPP / Apache

## Installation Guide
### Setup Server
	Install XAMPP or WAMP
	Start Apache & MySQL
### Project Setup

Move project folder to:

htdocs/
Database Setup

Open browser:

http://localhost/phpmyadmin
Create a database (as per project file)
Import .sql file from /DATABASE FILE/
